# Workflow Templates

Use these templates only when the project needs the corresponding document and has no existing owner. Adapt paths and terms, omit unused fields, and keep project-specific decisions. The bundle does not require installing the entire set.

- [workflow.md](workflow.md): one source choice and canonical record locations.
- [triage-states.md](triage-states.md): readiness and state meanings.
- [execution-policy.md](execution-policy.md): delivery roles, proof, and authority defaults.
- [domain.md](domain.md): existing domain-language and ADR owners.
- [prd-template.md](prd-template.md): product intent and acceptance expectations.
- [issue-template.md](issue-template.md): a bounded work item.
- [worker-thread-template.md](worker-thread-template.md): delivery context when dispatch is authorized.
- [reviewer-thread-template.md](reviewer-thread-template.md): read-only review context when review is authorized.

Keep only links to documents actually present when adapting this index into a project.

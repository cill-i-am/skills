# Route a workload to its implementation

Use the [release catalogue](source-map.md) for the exact guide, host and API. Search the package export map when a generated service reference covers more resources than the guide.

| User intent | Select and verify |
|---|---|
| Model a durable business process or push a live view | Use `@alchemy.run/domain`. Model commands, events, aggregates, views, queries and projections. Use policies/sagas for reactions and external systems for effects. Verify stories in memory with concurrent histories, view authorization and replay/backfill of old events before changing hosting. Choose Cloudflare, Rivet or Effect Cluster; check live subscribers after ownership changes. HTTP, CLI and MCP exposure each need an explicit boundary. |
| Durable actors or distributed jobs | Rivet supports durable objects, streams, sockets and managed/self-hosted nodes. For Effect Cluster select entities, pools, singleton/cron/workflow and storage. Check recovery after runner restart, shard ownership and client routing. |
| Run a disposable program | Choose E2B templates/warm snapshots, Daytona snapshots/volumes, Modal apps/functions/servers, Archil durable disks/branches, Boat environments/snapshots, or ECS Nitro according to the required host, networking, persistence and runtime. Separate build image, persistent storage and per-job compute. Keep provider tokens outside the guest. Verify timeout, failure teardown and retained storage. |
| Store or query data | Use R2/S3 for objects, KV for its consistency model, DOs for per-key coordination, D1/Turso for SQLite, or a managed SQL provider for relational requirements. Choose direct, Hyperdrive, pooled or private origin according to host. For Neon, PlanetScale and Prisma select branch, role, engine and migration owner. For Turso select organization, group, database and token. Build SQL clients in construction; issue queries in handlers. |
| Host a frontend | Select the exact host/framework pair in the tagged examples. Check static/SSR/prerender, assets, per-entrypoint caching, environment exposure, HMR and at least one dynamic route. The release includes Vite, Astro, Next.js, React Router, SvelteKit, Nuxt, SolidStart, TanStack Start, Foldkit, vinext, Waku and additional host-specific adapters. |
| Cloudflare compute, events or data | Check Worker export/entrypoint, gradual deployment, DO class migration, container image/start/port/snapshot lifecycle, queues, Workflows vs Effect workflows, K2 streams, Basin, Instant KV, cache and private Hyperdrive. Route AI, browser, AI Search, DNS, Access, email, logs and account resources through the exact service reference. Identify which part is emulated. |
| AWS or GCP workloads | Select AWS Lambda Web Function/alias/streaming, ECS/EC2/EKS, event sources/sinks, Bedrock, RDS/DSQL or the specific service. Test partial batch failure before retrying a whole batch. Inspect Floci support per resource. On GCP select Cloud Run service/job, Pub/Sub/Eventarc, storage, SQL or AI and verify workload identity, private networking, ingress and deploy region. |
| Docker/Kubernetes or hosted services | Check engine context, registry, remote build cache, network endpoints, volume lifetime, readiness and cleanup. Kubernetes resources may be managed as manifests or Helm. For Fly/Railway/Hetzner verify placement, volume persistence, domains/DNS, service identity and exactly which preview resources are owned by the stage. |
| Host Git or integrate GitHub | A smart-HTTP Git service has repository storage, auth, PR and GitHub-compatible APIs. GitHub provisioning instead manages repositories, rulesets, App credentials and PR comments. Verify an authenticated operation, denied operation and the correct storage/cleanup owner. |
| Identity, billing, observability or certificates | Better Auth needs session propagation and one migration owner. Stripe needs test mode, pricing/tax model and idempotent webhook processing. Axiom needs dataset, ingest credential, dashboard, notifier and a received trace. ACME needs DNS issuer/zone, renewal and certificate consumer. Doppler and Infisical require scoped runtime/CI secret sourcing. |
| Extend Alchemy or use low-level tooling | Start from the release export map and provider lifecycle suite. Contributions supply CLI/auth/state. Redis, SQL, frontend adapters, runtime utilities and preview-package tooling have distinct packages. Check a package's public manifest and release availability. |
